# বাজার দর | BazarDor

**BazarDor** is a web-based product price tracking application that helps users explore products, browse categories, and stay updated with the latest market prices in one place.

## Technologies Used

- **Next.js** – React framework for building modern web applications.
- **React** – For building interactive user interfaces.
- **TypeScript** – For type-safe and maintainable code.
- **Tailwind CSS** – For responsive and modern UI design.
- **REST API** – For fetching product and category data.
- **Better Auth** – Handle authentication features such as user registration, login, and session management.

## Key Features

1. **Product Price Tracking** – View product prices and monitor price changes.
2. **Dynamic Categories** – Browse products through dynamically loaded categories.
3. **Product Search and Exploration** – Explore available products and find relevant information easily.
4. **Price Change Indicators** – Identify products with increasing or decreasing prices.
5. **Responsive Design** – Enjoy a user-friendly experience across desktop, tablet, and mobile devices.
